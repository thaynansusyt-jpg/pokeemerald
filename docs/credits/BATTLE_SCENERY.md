# Cenários de batalha 0.7

Arte de CFRU, distribuída no repositório Team Aqua como livre para uso com créditos.
Créditos: equipe CFRU, Skeli789 e Shiny-Miner. Arquivos e termos originais:
https://github.com/monhacks/teamaquas-assets/tree/main/Battle%20Backgrounds/CFRU
https://github.com/Skeli789/Complete-Fire-Red-Upgrade
https://github.com/Shiny-Miner/CFRU-expansion/tree/Experiments

Adaptação técnica: conversão dos cenários interiores/ginásio para tiles/paleta de GBA.
Os fundos de grama, mata, areia, rocha, caverna e água usam os arquivos prontos para Emerald.
A integração usa a infraestrutura de batalhas de pokeemerald-expansion; não mistura o motor FireRed/CFRU com o motor Emerald.
